Процесс пилота Технотека.ИИ

Как организация заполняет карточку разработки — с автозаполнением или вручную, — как её проверяет модератор и откуда берутся оба КПЭ пилота.

Организация (МСП / НИИ) Система Технотека.ИИ Команда проекта (модератор)

Схема широкая — переключите масштаб и листайте вбок.

  • Скруглённый прямоугольник — шаг: с человечком делает человек, с шестерёнкой — система.
  • Ромб с крестом — развилка: дальше идёт одна из веток.
  • Тонкий круг / жирный круг — начало и конец; с часами — по наступлении срока.
  • Скобка с пунктиром — пояснение к шагу.

Границы прототипа

Есть — только то, что нужно для пилота и КПЭ

  • Вход организации по ссылке-приглашению, без регистрации
  • Загрузка файлов и автозаполнение с цитатами-источниками
  • Одна форма карточки, собранная из схемы полей
  • Ручной режим той же формы — для сравнения времени
  • Модерация по чек-листу: принять или вернуть
  • Выгрузка в Excel для расчёта КПЭ

Нет в версии 1 — сознательно

  • Учётные записи, пароли и роли (модератор один, вход по логину)
  • Уведомления по почте — ссылку команда отправляет сама
  • Публикация в Витрину и интеграции
  • Распознавание сканов (OCR); длинные документы через RAG — позже, в итерации качества D08
  • Дашборды и история версий — КПЭ считаются по выгрузке
  • Создание приглашений в интерфейсе — одна команда в консоли
